给大学生用的外卖选择小助手。**打开就给你一个具体的建议，不用填任何东西。**

> 为什么做、怎么做，看这几份文档：
> - `research.md` —— 需求研究（3 个同类产品的五维度比较）
> - `PRD.md` —— 产品需求（4 个页面 + 41 条验收标准）

> - `AGENTS.md` —— 我和 AI 协作的规则

## 环境要求

- **Node.js 18 或更高**（本项目在 **Node 22.22.2** 上开发并验证）
- 先确认一下装没装：

```bash
node -v
npm -v
```

两条都打印出版本号就说明没问题。没装的话去 <https://nodejs.org> 下 LTS 版。

```bash

```

终端会打印一行类似这样的地址：

```

```

**浏览器打开这个地址。** 想停掉就在终端按 `Ctrl + C`。

端口固定是 **5173**。如果提示端口被占用，说明已经有一个在跑了——直接打开地址即可；
或者关掉之前那个终端窗口。

改代码会自动刷新页面，不用手动重启。

## 数据存在哪

**全部存在你自己的浏览器里**（localStorage），不上传任何服务器。

所以有三件事你得知道：

- 换个浏览器、换台电脑，看到的是**空的**
- 清浏览器缓存 = **数据没了**（本期没有备份手段）
- 别人打开同一个网址，看到的是**他自己的**清单

三个存储键：

| 键 | 存什么 |
|---|---|
| `chisha:items` | 清单条目 |
| `chisha:filter` | 过滤条件 |
| `chisha:history` | 历史记录（最多 20 条） |

## 四种页面状态怎么看

首页有四种状态。**其中只有两种能自然遇到**，另外两种是给第 3 周接真实接口预留的位置。

| 状态 | 什么时候出现 | 怎么看到 |
|---|---|---|
| 成功 | 有候选，正常显示 | 直接打开 `http://localhost:5173` |
| **空** | 候选为 0：清单被删光，或过滤条件把候选全排除了 | 去「我的清单」把条目删光，再回首页 |
| 加载中 | —— **现在遇不到** | 地址栏加 `?state=loading` |
| 错误 | —— **现在遇不到** | 地址栏加 `?state=error` |

**为什么"加载中"和"错误"现在遇不到**：数据全部来自浏览器本地存储，是**同步读取、不联网**的，
所以既没有"等待"，也没有"请求失败"。这两种状态是给**第 3 周接真实接口**预留的位置——
那天数据要过网络，它们才会真的发生。现在就把它们做出来、并且能手动调出来看一眼，
是为了那时候不用回头补。

**手动触发之后怎么退出**：把地址栏里 `?state=loading` 或 `?state=error` 整段删掉再回车。
（加了参数之后点导航**不会**退出这个状态，因为参数还在地址里。）

**关于「空」状态的一个提醒**：开发的时候手上永远有那 50 条内置数据，**你永远看不到空**；
但真实的新用户第一次打开、或者把清单删光时，它就是空的。所以这一种最容易被忽略——
而它恰恰是用户最需要引导的时候。

## 遇到问题

**装依赖很慢或者失败**
换国内镜像再试：

```bash
npm install --registry=https://registry.npmmirror.com
```

**页面是白屏 / 某块不显示**
按 `F12` 打开开发者工具，点 `Console` 看有没有红色报错。有的话把红色那几行记下来。

**想从头来一遍（清空所有数据）**
按 `F12` → `Application` → 左侧 `Storage` → `Clear site data`，然后刷新页面。
清单会被重新播种成内置的 50 条。

**「换一个」换不动了**
如果清单里只剩 1 个条目，页面会提示「现在只有 1 个可选」——这是设计如此，
不是坏了。去「我的清单」加几条，或者点「恢复默认库」。

## 本项目不做什么

不是外卖 App。**不点餐、不配送、不比价、不算优惠、不登录、不下单。**
它只处理你**打开外卖 App 之前的那一刻**——那种「我根本不知道想吃什么」的卡顿。
